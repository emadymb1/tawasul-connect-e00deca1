



Rest API

API Documentation
البدء
Every endpoint lives under https://se.fiksutilitoimisto.fi/modules/Rest%20API/api.php/v2. Send your key in an Authorization header:

curl -H 'Authorization: Bearer gib_your_key_here' \
  'https://se.fiksutilitoimisto.fi/modules/Rest%20API/api.php/v2/students?pageSize=25&sort=surname'
Collections accept page, pageSize, sort, search and fields, plus the filters listed for each resource. Add gibbonSchoolYearID to any request to work in a year other than the current one.

The full machine-readable specification is available at /openapi.json, ready to paste into Postman, Insomnia or Swagger UI.

Authentication
API keys (gib_...) are created under Manage API Keys and suit server-to-server integrations.
User tokens (tok_...) come from POST /auth/login and act as that person, subject to their Gibbon roles.
A token can be renewed with POST /auth/refresh and cancelled with POST /auth/logout.
